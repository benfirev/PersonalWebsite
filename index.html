Code Visualizations

I enjoy writing software to visualize geometric concepts. Here are three examples: one for rendering sublevel sets of Morse functions, one for simulating Hamiltonian flow, and one for graphing a scalar function on the 2-sphere using height-angle coordinates. The full source code can be found on my GitHub.
